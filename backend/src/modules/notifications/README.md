# Notifications module

Owner: Ayyan

Handles all notification delivery and persistence for the platform.

## Planned responsibilities

- **Mentions** — notify users when they are @mentioned in a comment
- **Comment notifications** — notify document owners when a new comment is added
- **Reply notifications** — notify comment authors when someone replies to their comment
- **Document sharing notifications** — notify users when a document is shared with them
- **Permission change notifications** — notify users when their access level changes
- **Document update notifications** — notify collaborators when a document is edited

## Status

Initial scaffold. Depends on User and Document models from the auth and documents modules.
