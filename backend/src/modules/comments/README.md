# Comments module

Owner: Ayyan

Handles all commenting, discussion, and mention functionality within documents.

## Planned responsibilities

- **Create comments** — add a new comment to a document
- **Reply to comments** — respond to an existing comment thread
- **Mention users** — @mention users within a comment to trigger notifications
- **Resolve comments** — mark a comment thread as resolved
- **Delete comments** — soft-delete or hard-delete a comment

## Dependencies

Requires User model (auth module) and Document model (documents module) before full implementation.
